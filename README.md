# Centrala 3 — HR i finanse

Projekt należy wkleić do osobnego, chronionego Arkusza Google.

Uruchom kolejno:

1. `finInstall`
2. `finLoadDemo`
3. `finValidate`

Identyfikator Arkusza wklej w Plannerze przy kluczu `HR_FINANSE_FILE_ID`.

Arkusza nie należy udostępniać kierownikom ani pracownikom. Planner może działać jako aplikacja wdrożona przez właściciela i przekazywać użytkownikom wyłącznie zagregowane wyniki.
